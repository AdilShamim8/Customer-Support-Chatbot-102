# Support

## Where to Get Help

| Channel | Use for | Response time |
| ------- | ------- | ------------- |
| [GitHub Issues](https://github.com/AdilShamim8/Customer-Support-Chatbot-102/issues) | Bugs, feature requests | Best effort, 2-3 days |
| [GitHub Discussions](https://github.com/AdilShamim8/Customer-Support-Chatbot-102/discussions) | Q&A, architecture questions | Community |
| [Security Advisories](https://github.com/AdilShamim8/Customer-Support-Chatbot-102/security/advisories) | Vulnerabilities only | 48 hours |

## Before Opening an Issue

1. Search existing issues - your problem may already be solved.
2. Check the [Troubleshooting section](docs/runbooks/incident-response.md).
3. Collect the basics: OS, Python version, Docker version, error traceback,
   and the smallest reproduction steps.

## Commercial Support

This project is maintained as a reference implementation of a
production-grade RAG system. For production deployments, review the
[operations documentation](docs/operations/slo.md) and adapt the provided
runbooks, SLOs, and infrastructure manifests to your organization.
