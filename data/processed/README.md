# Processed Documents

Intermediate chunked output - **derived data, never edited by hand**.
Regenerated by the ingestion pipeline from `data/raw/`. Last updated:
2026-10-15.

## What Lives Here

- `chunks.jsonl` (and per-source chunk files): the parsed + chunked
  corpus with per-chunk metadata:
  `{"content": "...", "doc_id": "...", "source": "file.md",
     "chunk_index": 7, "token_count": 412}`

## The Rule

If a chunk looks wrong, fix the **source document or the chunking
strategy** - then re-run the pipeline. Hand-editing here is overwritten
on the next ingest and silently diverges from the raw source (the exact
"index corruption" failure mode the rebuild runbook guards against).

## Pipeline Position

```
data/raw ──(parse)──> documents ──(chunk)──> data/processed ──(embed)──> indexes
   truth                  parsed                intermediate              derived
```

## Rebuild

```bash
python scripts/ingest_documents.py --source-dir data/raw
python scripts/build_index.py --build --input data/processed/chunks.jsonl
python scripts/build_index.py --verify
```
